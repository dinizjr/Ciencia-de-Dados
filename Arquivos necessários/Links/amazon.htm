Nível gratuito da AWS (período de introdução de 12 meses):

Essas ofertas do nível gratuito estão disponíveis somente para novos clientes da AWS, por 12 meses, a partir da data do seu cadastro na AWS. Quando o período de 12 meses de uso gratuito expirar, ou se o uso da aplicação ultrapassar os níveis de uso gratuito, você pagará taxas de serviço padrão conforme o uso (consulte as páginas de serviço para obter mais detalhes de preço). Há restrições; veja os termos da oferta para obter mais detalhes.

Elastic Compute Cloud (EC2)

  • 750 horas de uso de instância Linux t2.micro do Amazon EC2 (1 GiB de memória e suporte à plataforma de 32 e 64 bits) – horas suficientes para executar continuamente todos os meses*
  • 750 horas de uso de instância t2.micro do Amazon EC2 com Microsoft Windows Server† (1 GiB de memória e suporte para plataformas de 32 e 64 bits) – horas suficientes para executar continuamente a cada mês*
  • 750 horas de um Elastic Load Balancer compartilhado entre Classic e Application Load Balancers, 15 GB de processamento de dados para Classic Load Balancers e 15 LCUs para Application Load Balancers*
  • 30 GB de Amazon Elastic Block Storage em qualquer combinação de uso geral (SSD) ou magnético, além de 2 milhões de E/S (com EBS magnético) e 1 GB de armazenamento de snapshots*
  • 500 MB/mês de armazenamento do Amazon Elastic Container Registry para novos clientes*

Amazon Simple Storage Service (S3)

  • 5 GB de armazenamento padrão do Amazon S3, 20.000 solicitações GET e 2.000 solicitações PUT*

Amazon Elastic File System (EFS)

  • 5 GB por mês de capacidade gratuita do Amazon EFS*

Amazon Relational Database Service (RDS)

  • 750 horas de uso de instâncias db.t2.micro Single-AZ do Amazon RDS para execução de MySQL, PostgreSQL, MariaDB, Oracle BYOL ou SQL Server (executando o SQL Server Express Edition) – horas suficientes para executar uma instância de banco de dados continuamente todos os meses*
  • 20 GB de armazenamento de banco de dados em qualquer combinação de armazenamento de propósito geral (SSD) ou magnético do RDS
  • 10 milhões de E/Ss (para uso com o armazenamento magnético do RDS; E/Ss em armazenamento de propósito geral (SSD) do RDS não são cobrados separadamente)
  • 20 GB de armazenamento de backup para seus backups de banco de dados automatizados e qualquer snapshot de banco de dados iniciado pelo usuário

Amazon Cloud Directory

  • 1 GB de armazenamento ao mês*
  • 10 mil solicitações de gravação ao mês*
  • 100 mil solicitações de leitura ao mês*

Amazon Connect

  • 90 minutos de uso do Amazon Connect por mês*
  • Um número para receber ligações diretas a ramal (DID) locais para a região da AWS*
  • 30 minutos ao mês de chamadas DID locais (para a região da AWS) recebidas*
  • 30 minutos ao mês de chamadas locais (para a região da AWS) efetuadas*
  • Para regiões nos EUA, um número de chamada gratuita nos EUA para uso mensal, além de 30 minutos ao mês de chamadas gratuitas recebidas nos EUA*

Amazon GameLift

  • 125 horas por mês de uso da instância c4.large.gamelift sob demanda do Amazon GameLift*
  • 50 GB de armazenamento de propósito geral (SSD) do EBS*

Transferência de dados

  • 15 GB de transferência de dados para fora e 1 GB de transferência de dados regionais agregada para todos os serviços da AWS*

Amazon Data Pipeline

  • 3 pré-condições de baixa frequência executando na AWS por mês*
  • 5 atividades de baixa frequência executando na AWS por mês*

Amazon ElastiCache

  • 750 horas de uso de nó cache.t2micro do Amazon ElastiCache; horas suficientes para executar continuamente todos os meses.*

Amazon CloudFront

  • 50 GB de transferência de dados para fora e 2.000.000 de solicitações HTTP e HTTPS do Amazon CloudFront*

Amazon API Gateway

  • 1 milhão de chamadas de API por mês*

Amazon Sumerian
